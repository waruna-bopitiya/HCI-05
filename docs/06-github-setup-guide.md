# GitHub Repository Setup

1. Create a **public** repository named `fitflow-redesign`.
2. Do not initialize it with another README if this prepared folder will be pushed.
3. Open the extracted `fitflow-redesign` folder in VS Code.
4. Run:

```bash
git init
git add .
git commit -m "Initial FitFlow redesign repository setup"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/fitflow-redesign.git
git push -u origin main
```

5. Configure protection/rules for the `main` branch.
6. Confirm the GitHub Actions repository check passes.
7. Add the final GitHub repository link to the lab report.
