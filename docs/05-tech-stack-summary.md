# Recommended Technology Stack

- **Frontend:** React Native + React Native Web
- **Backend:** Node.js / NestJS
- **AI Service:** Python / FastAPI
- **Database:** PostgreSQL
- **Authentication:** Firebase Authentication
- **Notifications:** Firebase Cloud Messaging
- **Media:** Cloud object storage
- **Communication:** REST APIs + WebSockets
- **CI/CD:** GitHub Actions

This combination was selected for its balance of cross-platform development, performance, real-time support, security, maintainability, and AI/ML integration.
